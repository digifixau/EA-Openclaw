# Shannon Instagram Story

## Download
The rendered video is available as a GitHub release asset or can be regenerated locally.

## Regenerate
```bash
cd remotion-composer
npx remotion render src/index.tsx Explainer ../output/shannon-story.mp4 \
  --props ../projects/shannon-instagram-story/renders/.remotion_props.json \
  --width=1080 --height=1920
```

- **Duration:** 17 seconds
- **Scenes:** Hero Title → 96% Stat Card → Comparison → KPI Grid → CTA
